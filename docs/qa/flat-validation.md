# 固定斜视角二维小样验收

日期：2026-10-25。

入口：http://127.0.0.1:5173/garden-2d.html 。

## 实现与边界

新增独立二维页面与 Canvas 2D 绘制器，复用现有场景状态模块。5 份写实透明素材可分别拖动和缩放，按根部位置自动排序遮挡、调整远近大小；接触阴影和淡投影实时随物件移动。背景是固定图片，建筑、地表与步石不可编辑，不进行实时重新打光或相机旋转。

19 个初始实例，存储键 `tingjian-flat-v1`。3D 只新增比较链接，保留现有代码、全部素材和三份存档。
