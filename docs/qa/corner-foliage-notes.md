# 近景叶片暗部修正

2026-10-24。

## 证据

- `fern_02`、`calathea_orbifolia_01`、`periwinkle_plant` 当前入口 glTF 均明确 `metallicFactor: 0`，排除金属度默认值导致的黑面。
- 三者均使用 `doubleSided: true`、`MASK` 和 Alpha 阈值 0.5；已有 AO 强度为 0.35、法线强度为 0.5。本次不改这些输入和原始纹理。
- 实际 `realism-angle.png` 的深黑集中于背光蕨叶和宽叶的叶背。Three.js r180 标准物理材质 `RE_Direct_Physical` 使用 `saturate(dot(normal, light.direction))` 作为直接漫反射系数，完全背光面只有环境光，且没有薄叶透光表现。
- 蕨类和宽叶网格不含顶点颜色；花卉有顶点颜色，因此顶点颜色不可能是三种植物共同暗面现象的原因。

## 实现

`src/realism-foliage.js` 导出 `prepareRealismFoliage(material)`，在模型加载时仅应用于写实植物材质。保留标准 PBR 反射，增加随现有灯光方向变化的薄叶背光漫射近似：最大背光强度为同一灯光正面强度的 42%，掠射角有不超过 12% 的柔和过渡。

新增项使用 Three.js 已经计算遮挡的 `directLight.color`；没有固定绿色、自发光或无条件提亮。Alpha 裁切、深度、粗糙度和法线贴图保持原样。它是轻量艺术近似，不是完整的次表面散射或体积透射。

本文件只负责材质；是否启用叶片接收投影由场景模块决定。当前场景此前为植物禁用了 receiveShadow，新的材质仍能随光照方向变化，但无法补回未接收的投影。若后续开启，透光项会跟随同一阴影强度。

验证边界：离线确认注入位置和 r180 GLSL 函数签名一致，并执行 JavaScript 语法检查。最终 WebGL 编译、三机位画面和交互由主任务浏览器检查。

## 首轮近景反馈后的宽叶高光校正

`corner-first-pass.png` 显示宽叶有过亮银白高光。对宽叶纹理 Alpha > 127 的 2,388,772 个像素统计，原 ARM 绿通道粗糙度最小 44/255、中位数 109/255、最大 177/255，即多数表面粗糙度约 0.43；源材质另有 specularColorFactor=1.12、ior=1.45。此问题符合较光滑表面反射 HDR/太阳光的表现，没有证据表明法线颜色空间配置错误。

仅对 `calathea_orbifolia_01` 设置粗糙度下限 0.62，并将物理材质 specularIntensity 降至 0.55；原图中更粗糙的区域保持更粗糙。其余植物保留原粗糙度，原纹理与法线强度均未修改。该校正是让展示场景中的叶片更柔和的材质调整，并非植物真实粗糙度测量结果。
