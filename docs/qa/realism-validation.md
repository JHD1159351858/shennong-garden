# 写实花境验证记录

日期：2026-10-24。入口：http://127.0.0.1:5173/?study=realism 。

结论：真实模型接入及编辑操作链路通过本地验证；参考图级视觉效果尚未通过。本次产物是可操作的实时 3D 场景，三个机位观察同一份场景数据。

## 本次变化

- 单独增加写实验证入口，保留原小样与其存档。
- 三种真实植物网格：羽叶蕨、宽叶绿植、粉花地被；一份实拍纹理景石。花丛由同一单株组合，复制摆放复用资源。
- 使用本地 PBR 碎石、泥土、苔石、木材与粉墙贴图；HDR 环境光、太阳光和半球补光。
- 俯视为正交编辑相机，斜视和侧面为透视相机；保留原有拾取、拖动、撤销重做、保存与导出。
- 首轮发现植物过稀、泥土偏暗、叶片暗部过重，替换饱满的完整植物变体，修正透明通道，并调整补光与近景取景。最终画面仍有明显的美术差距，未以功能通过替代视觉通过。

## 视觉结论与下一步

真实网格与实拍纹理提供了可辨认的叶脉、枝条、石纹、木纹，三个视角不再依赖平面立绘。但最终截图中的叶背和蕨叶仍有过硬暗部，地面与踏步较平，植物分布偏零散；缺少参考图的多层冠幅、细腻柔光和自然地表起伏。不能认定已经达到参考图的写实质量。

下一轮应先集中处理一个固定近景角落：校正双面叶片光照与透光表现，使用适合日式花境的成组植物和有厚度的苔藓/地被，再统一接触阴影与取景。通过这一个近景的视觉验收后，再扩大素材库。
