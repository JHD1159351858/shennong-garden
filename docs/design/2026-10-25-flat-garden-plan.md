# 固定斜视角二维对比小样

用户已选择新增固定机位的二维方案，原 3D 版本与存档保留。

1. 使用 imagegen 内置工具生成一张无前景植物的日式庭院底图，以及五份真正透明的写实植物/景石素材。统一机位与左上方柔和日光，明确为 AI 生成，不宣称实拍。
2. 独立 `garden-2d.html`、`src/flat-main.js`、`src/flat-scene.js`、`src/flat-style.css`、`src/flat-catalog.js`。场景复用现有 JSON 状态模块；编辑目标是叠加的植物与景石，建筑、步石及地表是固定底图。
3. Canvas 2D 实现透明像素拾取、远近尺寸变化、遮挡排序、落地接触阴影和淡投影。保留拖拽、缩放、删除复制、撤销重做、本机保存与 PNG 下载；固定机位不提供旋转或相机切换。
4. 存储键 `tingjian-flat-v1` 与 3D 完全独立。新增两个方向的比较链接；生产构建包含两个 HTML 入口。
5. 验收以实际浏览器画面、拖拽一次历史提交、缩放、保存刷新、旧存档不变和真实 PNG 下载为准，运行现有状态测试与构建。
