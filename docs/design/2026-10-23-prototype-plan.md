# 庭间可操作小样实施计划

用户已选择第二张视觉方向，并授权先做 6–8 个素材、俯视拖拽、三个机位的小样。

目标：同一份可编辑 3D 庭院，在俯视、斜视、侧视之间切换。使用 HTML/CSS/JavaScript、Vite 和 Three.js。

1. 获取并核验 8 个模型，保存来源授权；通过模型实际加载和缩略图检查。
2. 建立庭院与相机、地面拖拽；通过同一实例在三机位下的可见性和落点一致性验证。
3. 实现参考图的顶部栏、右侧素材库、选中调整条；提供添加、移动、旋转、缩放、删除、撤销重做、本地保存和PNG导出。
4. 构建并在浏览器操作验收；记录素材风格差距与尚未接入的能力。

模块：src/catalog.js 为素材目录；src/garden-scene.js 为渲染和指针坐标；src/state.js 为场景与历史；src/main.js 为界面绑定；src/style.css 为布局。

本轮不做完整植物百科、挑战系统或 AI 服务。缩放表示视觉比例。素材采用可下载的真实模型，实际精细度不等同于概念图。
