# 写实花境角落验证

用户已批准上一轮提出的局部验证：3 种写实植物、景石和木廊，保留真实拖拽与三个视角，达到可比较的画质后再决定是否扩大替换。

1. 从有明确授权的官方资源获取 3 种植物和 1 种岩石及完整纹理；检查本地引用、几何与包大小。素材目录与原版本分离。
2. 用实拍 PBR 材质制作木廊、碎石与自然花床；用环境光照和有方向的柔和日照表现材质。场景是实时三维，不用整张效果图充当背景。
3. 保留俯视正交编辑；斜视和侧视采用透视近景。两种场景复用现有交互，写实试验使用独立入口 `?study=realism` 和存档键 `tingjian-realism-v1`。
4. 浏览器检查模型、地面与光照；实际完成添加、拖动、切换视角、保存恢复、图片导出；运行现有状态测试与构建。

文件分工：`src/realism-catalog.js` 与 `public/assets/realism/models/` 放素材；`src/realism-environment.js` 与 `public/assets/realism/surfaces/` 放环境；`src/garden-scene.js` 接入环境/相机；`src/main.js` 提供独立试验配置与存档；只给现有界面增加版本切换入口。

验收区分：功能验证通过不等于画质与参考图完全一致。最终提供实际运行截图与本地入口，明确剩余美术差距，不以新的生成概念图代替结果。不采购、部署或接入 AI 服务。
