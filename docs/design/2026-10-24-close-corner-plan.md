# 近景角落打磨

沿用已确认的日式庭院方向与实时 3D 技术，落实用户要求的叶片暗部、地面质感、植物层次三处改进。

1. 叶片：检查原始非金属参数，增加薄叶背光漫射近似。验证真实 WebGL 编译及叶背细节。
2. 地面：连续浅起伏、实体碎石和有厚度的踏步。摆放根部跟随同一高度函数，验证俯视拖动落地。
3. 植物：围绕景石布置后排宽叶、中层蕨类、前排花丛；近景相机保持真实透视。独立入口 `?study=realism&layout=corner` 和 `tingjian-realism-corner-v1` 存档，不覆盖先前作品。
4. 验证：同一窗口前后截图对比；实际拖拽、撤销重做、三个视角数据一致、刷新恢复、PNG 下载。最后运行现有状态测试与构建。

二维实拍拼贴更适合一个固定视角；本轮保留用户要求的三个连贯视角，不改为静态背景或整株朝向相机的立绘。参考图为视觉目标，最终结果以网页截图为准。
