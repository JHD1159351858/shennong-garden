# 庭间 · 庭院花境可操作小样

按第二张「日式庭院」方向制作的本地网页原型。采用 HTML / CSS / JavaScript、Three.js 和 Vite，8 种独立 3D 素材，三个相机观察同一份场景。

## 运行

```powershell
npm install
npm run dev
```

打开终端输出的本地网址，默认 http://127.0.0.1:5173/ ，自动进入二维花园。二维页顶栏「对比 3D」仍可进入三维近景版；原风格化三维小样可通过 http://127.0.0.1:5173/?view=3d 打开。不要直接双击 index.html，需要 HTTP 服务加载素材。

```powershell
npm test
npm run build
```

## 操作

1. 从右侧拖入素材，或先点素材再点庭院；会自动切换到俯视摆放。
2. 俯视下直接拖动已有素材。点选后用底部工具条调整朝向、大小、复制和删除。
3. 切换俯视、斜视、侧面观察，摆放数据保持一致。
4. 顶栏撤销 / 重做；Ctrl+Z 撤销，Ctrl+Shift+Z 重做。Esc 取消放置。
5. 每次编辑自动保存在当前浏览器本机，刷新恢复。清空可以撤销。
6. 「导出作品」下载当前视角的 PNG，不包含界面、网格和选中框。

## 文件

- `src/catalog.js`：素材目录；`public/assets/`：本地模型和贴图。
- `src/garden-scene.js`：3D 庭院、相机、拖动拾取、缩略图和截图。
- `src/state.js`：作品数据、撤销重做、保存校验；`tests/state.test.js`：9 个测试。
- `src/main.js`：操作与界面绑定；`src/style.css`：视觉布局。
- `ASSET-LICENSES.md`：来源及授权；`docs/qa/design-qa.md`：本次验证记录。

## 本轮范围

### 2026-10-25 二维花色与场景扩展

二维入口保持不变。现在提供 12 类物件、16 个素材版本：绣球有蓝、粉、紫、白四种颜色，庭院玫瑰有粉色和奶油色；新增雏菊、薰衣草、红枫、石灯、陶土花盆和长椅。素材卡片下可选花色，点选画布中的花卉后也能换色；花色变化支持撤销和保存。

顶部可以切换日式庭院、现代庭院、英式花园、露台花园，各自保存布置，刷新后返回最近场景。日式继续使用原 `tingjian-flat-v1` 存档；新场景使用各自独立的 storage key，3D 不受影响。场景建筑与地面是固定图片，植物和摆件可编辑。

### 2026-10-25 固定斜视角二维小样

打开 http://127.0.0.1:5173/garden-2d.html ，或点击 3D 页顶栏「二维对比」。二维页的「对比 3D」返回近景三维版，两者独立保存。

二维版采用 Canvas 2D、AI 生成写实透明素材与固定庭院底图，包含绣球、玉簪、观赏草、蕨类、苔石 5 种素材，初始 19 个可编辑实例。支持拖入/点选放置、移动、缩放、复制删除、撤销重做、本机自动/手动保存与 1600 × 1100 PNG 导出。前后摆放自动改变显示大小和遮挡顺序，阴影跟随实例位置。建筑、地表和步石属于固定底图；不提供二维相机切换或植物旋转。

独立存储键为 `tingjian-flat-v1`。源码入口为 `src/flat-main.js`，绘制/拾取在 `src/flat-scene.js`，素材目录为 `public/assets/flat/`。Vite 已配置双 HTML 入口，生产构建同时保留二维和三维页面。

实际验收见 `docs/qa/flat-validation.md`；素材来源、生成提示词和透明通道信息见 `docs/qa/flat-assets.md`。素材为 AI 生成写实图，不是实拍或经核验的植物品种图鉴。

### 2026-10-24 写实花境验证

近景打磨版入口：http://127.0.0.1:5173/?study=realism&layout=corner 。它增加薄叶背光漫射、较柔和的宽叶高光、连续浅起伏地面、4,200 个实体碎石及更密集的三层种植组合。46 个可编辑实例，独立存储键 `tingjian-realism-corner-v1`；顶栏可返回先前布局。材质与环境改进也应用于原写实入口，先前的摆放数据保持不变。实际截图与验证记录见 `docs/qa/corner-validation.md`。

打开 http://127.0.0.1:5173/?study=realism ，或点击原小样顶栏的「写实验证」。此入口使用 3 种真实植物模型、1 种景石模型，以及实拍 PBR 地表/木材贴图和 HDR 环境照明；保留俯视编辑与三个观察视角。模型和贴图均在本地，来源与 CC0 许可见 `docs/qa/realism-asset-sources.md` 和 `docs/qa/realism-surface-sources.md`。

写实版使用独立存储键 `tingjian-realism-v1`，原小样存档不变。新增素材目录为 `src/realism-catalog.js`，环境实现为 `src/realism-environment.js`。

实际浏览器已验证拖入、移动、旋转缩放、撤销重做、视角切换、刷新恢复和 PNG 下载。验证记录与截图见 `docs/qa/realism-validation.md`。这轮证明真实 3D 素材可以用于现有编辑器；画面尚未达到参考图，仍存在叶片暗部较硬、地表平面感和种植层次不足的问题。

### 原小样

完成小样的实际操作链路。模型采用风格化资源，植物细节、地表质感和场景密度尚未达到概念图。中文素材名描述外观，不作为真实品种鉴定和种植知识。

本机存储键为 `tingjian-garden-v1`，没有后端、账号或云同步。尚未接入 AI、挑战模式、完整植物分类和图层面板；不支持任意环绕相机。PNG 是图片，不能重新导入编辑。

当前开发验证在桌面浏览器完成，未进行真机触控验收。构建有 Three.js 主包体积提示，不影响本地构建成功。
